# Scribble

A Java desktop drawing application built with JavaFX, featuring digital drawing tablet support and responsive stroke rendering.

## Features
- Freehand drawing with custom brush sizes and color palette.
- Tablet input handling (pen pressure / pointer events).
- Clean MVC-oriented structure.

## Requirements
- Java 21 or higher
- Maven

## How to Run

```bash
git clone [https://github.com/adiyn/scribble.git](https://github.com/adiyn/scribble.git)
cd scribble

# run with maven
mvn clean javafx:run
```
